# Better Presentations with AI

Sharing deck, 30 minutes, 30 slides. One interactive HTML page.

## Open it

- **Locally:** download the repo, keep the folders together, open `deck.html` in Chrome, press **F** for full screen.
- **Online:** with GitHub Pages on (Settings → Pages → Deploy from branch `main`, folder `/`), the deck is at `https://<your-user>.github.io/<repo>/`.

## Files

| Path | What |
|---|---|
| `deck.html` | The deck |
| `index.html` | Redirects to `deck.html` (for GitHub Pages) |
| `img/` | Photos and slide screenshots used by the deck |
| `live/after.html` | The live "after" slides shown on slide 14 |
| `edits.json` | Empty; holds saved text edits on the hosted version |

## Keys

→ / Space next · ← back · F full screen · N speaker view · G overview · P pen · H highlighter · L laser · ? all keys
